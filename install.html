Install guide

Set Up Flash Analyst In About 10 Minutes

You need a Windows or Mac computer. You'll install Python (free), add one free add-on, then make your first report. No coding knowledge needed: you just copy and paste a few short commands.

  1. 1

    Install Python

    Go to python.org/downloads and download the latest Python for Windows. Open the installer and tick “Add python.exe to PATH” at the bottom of the first screen, then click Install Now.

    Go to python.org/downloads and download the latest Python for macOS. Open the downloaded file and follow the installer.

  2. 2

    Open A Terminal

    Press the Windows key, type cmd and press Enter. A black window called Command Prompt opens.

    Press Command + Space, type Terminal and press Enter.

    Check Python works by typing this and pressing Enter:

    python --version
    python3 --version

    You should see something like Python 3.12.4.

  3. 3

    Install The Free Add-On

    Flash Analyst uses one free add-on, called openpyxl, to create Excel files:

    pip install openpyxl
    python3 -m pip install openpyxl
  4. 4

    Put Flash Analyst In A Folder

    Make a folder called Flash Analyst in your Documents and save the file you bought into it (flash_analyst_basic.py or flash_analyst_pro.py). Then point the terminal at that folder:

    cd %USERPROFILE%\Documents\Flash Analyst
    cd ~/Documents/"Flash Analyst"
  5. 5

    Try The Demo

    This makes sample reports so you can see everything working. Use the name of your file (Basic or Pro):

    python flash_analyst_pro.py demo
    python3 flash_analyst_pro.py demo

    A new folder called demo_reports appears with Excel files inside. Open one!

  6. 6

    Make Your First Real Report

    Create the template, fill in the yellow cells in Excel, Google Sheets or Numbers, save it, then analyze it:

    python flash_analyst_pro.py template my_company.xlsx
python flash_analyst_pro.py analyze my_company.xlsx --prepared-by "Your Name"
    python3 flash_analyst_pro.py template my_company.xlsx
python3 flash_analyst_pro.py analyze my_company.xlsx --prepared-by "Your Name"

    Your report appears in the reports folder. Using accounting exports instead? Put them in one folder and analyze the folder: analyze "My Company".

Troubleshooting

If Something Doesn't Work

“python is not recognized” (Windows)

Python wasn't added to PATH. Run the installer again, choose Modify or reinstall, and tick “Add python.exe to PATH”. Or try typing py instead of python.

“No module named openpyxl”

The add-on isn't installed yet. Go back to step 3 and run the install command again.

“No such file or directory”

The terminal isn't in the folder with your file, or the file name is different. Repeat step 4 and check the file name matches exactly.

A certificate error on a Mac

Open your Applications folder, then the Python folder, and double-click Install Certificates.command. Then try again.

“couldn't find the numbers” when analyzing

The file needs years plus Revenue and Net Income. Use the template from step 6, or export a Profit & Loss report with one column per year (not monthly).
